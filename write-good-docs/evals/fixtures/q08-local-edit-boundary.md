# Trace viewer

The visualiser opens saved traces.

## Installation

Run `pipx install traceview==3.2.1`.

<a id="configuration"></a>
## Configuration

In order to configure the visualiser, it is necessary to set `TRACE_THEME` to `dark`. Then run `traceview open run.trace`. This configuration is used for the purpose of changing the visualiser's theme.

## Support

Send the trace identifier to the support team. Do not attach private trace contents.
