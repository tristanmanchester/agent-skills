## Original material in version 2

The following parts are original to this package:

- the trigger-oriented skill description;
- the source-driven documentation workflow;
- the hierarchy of truth, reader outcome, findability, clarity, and mechanics;
- the document-shape routing and templates;
- the common agent-failure guidance;
- the compact validation loop;
- the trigger and output-quality evaluation cases.

Agent Skills documentation informed the packaging, progressive-disclosure, description, and evaluation design. Those sources are listed in [the source map](references/source-map.md).

## Changes from the source guide

The source material was:

- condensed and reorganized around agent decisions rather than the guide's website taxonomy;
- separated into always-needed workflow instructions and conditional references;
- supplemented with instructions for reading repository evidence and preserving technical fidelity;
- supplemented with human-readability and common LLM failure modes;
- reduced to high-value rules, with the live guide retained as the edge-case source of truth;
- paired with Markdown-only evaluation cases for future iteration.
