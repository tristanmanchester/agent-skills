# Source Notes

This skill combines the original guest-insights reference with a targeted research pass on presentation practice, slide design, accessibility, multimedia learning, scientific talks, and Q&A.

## Integrated external sources

### Stanford Graduate School of Business — Matt Abrahams on planning, practicing, and presenting

URL: https://www.gsb.stanford.edu/insights/matt-abrahams-tips-techniques-more-confident-compelling-presentations

How it informed the skill:

- Treat presentation skill as a combination of planning, practice, and presenting.
- Give users practical anxiety-management and rehearsal steps rather than generic reassurance.
- Emphasize audience connection over self-evaluation.

Related files:

- `rehearsal-delivery.md`
- `presentation-workflows.md`
- `qa-stakeholders.md`

### Stanford Oral Communication Program — scientific presentations

URL: https://oralcommprogram.stanford.edu/tutoring/scientific-presentation

How it informed the skill:

- Use storyboarding to build narrative before slides.
- Use a bowtie structure for scientific talks: broad context → narrow technical question → broad implications.
- Adjust the depth of technical “data dives” to the audience.

Related files:

- `story-structure.md`
- `format-playbooks.md`
- `slide-design-and-visuals.md`

### Harvard Business Review — Chris Anderson / TED presentation advice

URL: https://hbr.org/2013/06/how-to-give-a-killer-presentation

How it informed the skill:

- Frame talks around a story and key takeaways rather than using a presentation as a compressed written report.
- Use the speaker’s presence to create meaning beyond what a document can do.

Related files:

- `story-structure.md`
- `presentation-workflows.md`

### Duarte — contrast and the Presentation Sparkline

URL: https://www.duarte.com/blog/ultimate-guide-to-contrast/

How it informed the skill:

- Make contrast a core principle across narrative structure, slide design, and vocal delivery.
- Use “what is / what could be” to create tension and movement.

Related files:

- `story-structure.md`
- `slide-design-and-visuals.md`

### Nielsen Norman Group — engaging reports and asynchronous presentations

URL: https://www.nngroup.com/articles/engaging-reports-presentations/

How it informed the skill:

- Translate metrics into relatable scenarios or analogies.
- Break up heavy text and use visuals, comparisons, checklists, quotes, and charts to improve scanning and engagement.
- Distinguish between live presentations and self-contained async materials.

Related files:

- `slide-design-and-visuals.md`
- `format-playbooks.md`

### University of Twente — Mayer’s multimedia learning principles summary

URL: https://www.utwente.nl/en/learning-teaching/educational-design/mayers-ed.-design-principles-1.pdf

How it informed the skill:

- Reduce extraneous material.
- Use signaling to direct attention.
- Avoid unnecessary duplication of narration and on-screen text.
- Segment complex material into digestible chunks.
- Prefer conversational language for learning-oriented presentations.

Related files:

- `slide-design-and-visuals.md`
- `format-playbooks.md`

### Microsoft Support — accessible PowerPoint presentations

URL: https://support.microsoft.com/en-us/accessibility/powerpoint/make-your-powerpoint-presentations-accessible-to-people-with-disabilities

How it informed the skill:

- Include accessibility checks as part of slide quality, not as an afterthought.
- Use unique slide titles, sufficient contrast, readable fonts, alt text, logical reading order, simple tables, and non-color cues.

Related files:

- `slide-design-and-visuals.md`
- `SKILL.md`

### Toastmasters International — public speaking and Q&A guidance

URLs:

- https://www.toastmasters.org/resources/public-speaking-tips
- https://www.toastmasters.org/magazine/magazine-issues/2021/mar/handling-the-qanda-session-with-confidence

How it informed the skill:

- Treat speaking confidence as a trainable skill improved by practice.
- Make Q&A explicit, invite questions deliberately, pause, and use body language and specificity to encourage audience participation.

Related files:

- `rehearsal-delivery.md`
- `qa-stakeholders.md`

### Wharton Communication Program — handling Q&A

URL: https://communicationprogram.wharton.upenn.edu/library/handling-qa/

How it informed the skill:

- Keep Q&A anchored in audience, purpose, and structure.
- Use simple structures to answer questions concisely and stay on message.

Related files:

- `qa-stakeholders.md`

## Integrated uploaded skill-authoring guidance

The skill was also revised using the uploaded Agent Skills resources:

- Keep the skill directory simple: `SKILL.md` plus focused `references/` files.
- Make the frontmatter description specific and trigger-oriented.
- Use progressive disclosure: keep the main `SKILL.md` focused and move detailed guidance into references.
- Avoid bundling scripts when the skill only needs procedural guidance and reference material.
- Preserve portability by using relative references and no environment-specific dependencies.
